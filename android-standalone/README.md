# Shimeji Overlay (Standalone Android App)

Отдельное автономное Android-приложение (ПК и интернет не нужны):
- **Поверх всех приложений** (`SYSTEM_ALERT_WINDOW` + `ForegroundService`), компактное плавающее окно только вокруг чубрика — не мешает нажимать на экран вокруг него.
- **Смешное падение при повороте и наклоне телефона**:
  - датчик гравитации/акселерометр (`TYPE_GRAVITY` / `TYPE_ACCELEROMETER`) с учётом ориентации экрана;
  - при наклоне, перевороте или смене ориентации чубрик теряет равновесие, кричит (`ААА!`, `ОЙ!`, `КУВЫРК!`), кувыркается в сторону наклона, шмякается о край экрана со сплющиванием и отскоком (`БУМ!`, `ШМЯК!`), крутит звёздочками над головой (`@_@`) и потом смешно вскакивает обратно;
  - можно схватить пальцем, перетащить и кинуть об стенки, 1 тап — прыжок, 2 тапа — кувырок.

## Готовый APK без Android Studio
Собирается автоматически через GitHub Actions: `.github/workflows/build-standalone-android-apk.yml` → артефакт `Shimeji-Overlay-Standalone-APK`.
