# Shimeji Hand Cam — Единая система (Android Overlay + Камера + Связь с ПК)

Нативное Android-приложение, работающее **и полностью автономно**, **и в единой связке с ПК-версией (`GCS Local Hub`)**:
- **Поверх всех приложений** (`SYSTEM_ALERT_WINDOW` + `ForegroundService`, не мешает нажатиям вокруг персонажа).
- **Единая система с ПК по Wi-Fi (`HubSyncClient` + `HubNsdDiscovery` + `HandoffOfferOverlayView`)**:
  - Автопоиск ПК в локальном Wi-Fi через mDNS (`_gcs-shimeji._tcp.`) или подключение по IP/QR.
  - Двусторонний перенос чубрика **ПК ↔ Телефон** с сохранением текущей эмоции (`neutral`, `happy`, `love`, `excited`, `scared`, `dizzy`, `angry`, `sleepy`):
    - **Телефон → ПК**: потяните чубрика к левому/правому/верхнему краю экрана и подержите ~0.4с (или нажмите «Отправить на ПК»).
    - **ПК → Телефон**: поверх любых приложений всплывает баннер **«Принять»** — можно нажать пальцем или показать камере открытую ладонь `✋`!
- **Смешное падение при повороте и наклоне телефона** (акселерометр/гравитация + смена ориентации, кувырки, сплющивание, звёздочки).
- **Управление ладонью через камеру прямо на телефоне** (CameraX + встроенный оффлайн MediaPipe Hand Landmarker на 21 точку):
  - `🤏 Щипок` — хватать и перетаскивать чубрика по экрану в воздухе.
  - `✋ Помахать ладонью` — погладить (`♥` сердечки и румянец), взмах вверх — прыжок, открытая ладонь при переносе — принять чубрика с ПК.
  - `☝️ Указательный палец` — позвать чубрика бежать к руке.
  - `✌️ Два пальца (Peace)` — весёлый прыжок с сердечками.
  - `✊ Кулак` — уложить спать (`Zzz`).
- **8 живых пиксельных эмоций**: Спокойный, Радостный (`✨`), Влюблённый (`♥` + румянец), В восторге, Испуганный (`💧`), Голова кружится (`★`), Злится (`💢`), Сонный (`Zzz`).

## Готовый APK без Android Studio
Собирается автоматически через `.github/workflows/build-handcam-android-apk.yml` (включая скачивание оффлайн-модели `hand_landmarker.task` внутрь APK) и публикуется в GitHub Release `android-handcam-latest`.
